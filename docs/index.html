McGregor Fellowship Question Bank Tester

Upload a CSV question bank, pick a model, save your API key locally, and preview the request payload for evaluation.

Your CSV should use headers: Q#, Question, Category, and Difficulty.

Updated: sample requests now redirect to a second results page at results.html. If you still see the old version, refresh the browser with a hard reload.

1. OpenRouter model & API key

Select OpenRouter and choose a model ID to use for the request.

Keys are stored locally in your browser only. This site is static and does not keep your API key on a server.

Model lists are illustrative and may change. Always verify current model names with OpenRouter before sending requests.

2. Upload your CSV question bank

Required format: first row headers must include Q#, Question, Category, and Difficulty.

Q#\tQuestion\tCategory\tDifficulty
Q1\tWho was Olympias?\tFactual Accuracy\tBasic
Q2\tWhat was Olympias' relationship to John Chrysostom?\tFactual Accuracy\tBasic
Q3\tWhat were the ecclesiastical positions held by the leadership of Hagia Sophia?\tFactual Accuracy\tIntermediate
Q4\tDescribe the institutional nature of the monastery Olympias founded near Hagia Sophia in Constantinople.\tCompleteness / Factual Accuracy\tIntermediate

3. Build payload

4. Run a quick sample request

This builds and sends one request for the first question through OpenRouter using the selected OpenRouter model ID. If your OpenRouter key works and your browser allows the request, it will open the response on a second page.

Supported sample models include OpenRouter model IDs such as `anthropic/claude-opus-4.1`, `openai/gpt-4o`, `x-ai/grok-2`, `google/gemini-2.5-flash`, and `deepseek/deepseek-v4-pro`.

Browser execution may still be blocked by CORS policies.

Deploy with GitHub Pages from the docs/ folder in this repository.
